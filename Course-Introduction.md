COURSE DESCRIPTION 
 
This course introduces students to the principles, methodologies, and tools of Agentic Software Engineering, an emerging paradigm that integrates artificial intelligence agents 
into the software development lifecycle. Students will explore how AI-powered systems assist in requirements analysis, software design, coding, testing, documentation, 
deployment, and maintenance. The course emphasizes human-AI collaboration, prompt engineering, autonomous workflows, responsible AI practices, and evaluation of agent
generated outputs. Through hands-on projects and real-world case studies, students will develop practical skills in building, managing, and evaluating AI-assisted software 
solutions while applying professional engineering standards, ethical considerations, and quality assurance practices. Upon completion of the course, students will be able to 
design and implement agent-assisted software development workflows, critically assess AI-generated artifacts, and leverage modern AI tools to improve productivity, software 
quality, and innovation in engineering projects.

• Attend lectures, laboratories, consultations, examinations, and project reviews. 
• Submit requirements through the designated LMS and GitHub repository. 
• Do not commit passwords, API keys, personal data, or confidential information. 
• Each student must have a traceable and defensible project contribution. 
• Follow software, dataset, model, and open-source license requirements. 
• Report failed tests, system limitations, security risks, and unresolved defects honestly.
